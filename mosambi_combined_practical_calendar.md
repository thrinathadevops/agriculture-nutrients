## HOW TO READ THIS CALENDAR

Each 15-day period has **6 actions only:**

```
SPRAY  → Do ONCE on Day 1 of period (Morning 6–9 AM)
DRIP 1 → Add to header tank on Day 3  (watering day)
DRIP 2 → Add to header tank on Day 6  (watering day)
DRIP 3 → Add to header tank on Day 9  (watering day)
DRIP 4 → Add to header tank on Day 12 (watering day)
DRIP 5 → Add to header tank on Day 15 (watering day)
```

**Before every drip session:** Run 5 min plain water first
**After every drip session:** Flush 15 min plain water — MANDATORY
**Spray:** 100L spray tank | **Drip amounts:** Per 100L header tank water

## MANDATORY RULES BEFORE YOU START

```
WAE PREPARATION (every time before use):
→ Take 3L settled Wood Ash water (top clear liquid only)
→ Mix with 3L MOE in bucket → wait 10 min → stir
→ Test pH → must be 6.5–7.5
→ If above 7.5 → add more MOE → retest
→ Only use after pH confirmed safe

VAM RULES:
→ Use same day — NO fermentation
→ Never spray VAM — drip only
→ Water field before VAM drip → apply → water again after

TRUNK DRENCH (every DRIP 2 session):
→ Separately from drip tank
→ Pour 5L of TRCH 10% concentrate at trunk base in circle
→ Do this while drip is running — does not need separate trip

COMPATIBILITY — NEVER on same day:
→ WAE spray + NPKD drip : 3-day gap needed
→ LRK spray + any mix   : LRK always alone in spray tank
→ VAM drip + TRCH drip  : 7-day gap needed (calendar already handles this)
→ MOE/BTM + NPKD        : 2-day gap needed (calendar handles this)
```

# PERIODS 17–18 | DAYS 241–270 | HARVEST

## Harvest Decision Checklist

```
✅ Harvest when ALL of these are confirmed:
   Brix reading    → Above 10.5 (test 3 fruit minimum)
   Juice content   → Above 42% by weight
   Peel color      → Light green to yellow-green
   Peel feel       → Smooth, slightly soft when pressed gently
   Sound           → Light thud when tapped — not hollow
   Size            → 6–8 cm diameter

❌ Do NOT harvest if:
   Peel still dark green and hard
   Brix below 9
   Hollow sound when tapped
```

## During Harvest Period

