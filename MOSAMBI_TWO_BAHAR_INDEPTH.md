# ⚠️ SECTION 0 — HOW TO READ "MUST-DO" (MIXING RULES)

```
THE MOST IMPORTANT THING TO UNDERSTAND:

When Must-Do shows 3 items, you do NOT always mix all 3 in one tank.
Some mix together. Some MUST be sprayed separately. Here is the rule:

🅐 MIX GROUP A — "Acid-safe" — CAN mix in one spray tank:
   → 00:52:34 (MKP), 13:00:45 (KNO3), 19:19:19
   → Zinc Sulfate, Manganese Sulfate, Borax, Boron
   → Micronutrient mix, Iron (Fe-EDDHA)
   → Urea (low dose)
   → These all mix together = ONE spray

🅑 CALCIUM — ALWAYS SEPARATE SPRAY (never with Group A):
   → Calcium Nitrate, Calcium Chloride, BTM (buttermilk)
   → WHY: Calcium + Phosphorus = white precipitate (calcium phosphate)
   →      Calcium + Sulfate = gypsum precipitate
   → Result: blocks nozzle + nutrients become unavailable
   → RULE: Spray Calcium on a DIFFERENT DAY or different session

🅒 COPPER / DISEASE — ALWAYS SEPARATE (alkaline):
   → Copper, Bordeaux, Streptocycline
   → Never mix with acids, fertilizers, or biologicals

🅓 BIOLOGICALS — ALWAYS SEPARATE:
   → TRCH, PLF, EJEV, NPKD, VAM
   → Never mix with any chemical (chemical kills them)

EXAMPLE — if Must-Do says "Zinc + Boron + Calcium":
   → Spray 1: Zinc + Boron together (Group A) — morning
   → Spray 2: Calcium alone (Group B) — evening OR next day
   → NOT all three in one tank!
```

# SECTION 1 — IN-DEPTH: FRUIT SETTING (The #1 Citrus Challenge)

## The Science You Must Understand

```
Citrus produces 100,000+ flowers per tree but sets only 1-2% to harvest.
Everything else DROPS. Your job = reduce the drop.

TWO DROP WAVES:
1. POST-BLOOM DROP (right after flowering) — weak/unpollinated flowers fall
2. JUNE DROP (physiological, 4-6 weeks after set) — tree self-adjusts crop load

WHAT CAUSES EXCESS DROP (your enemies):
→ Nitrogen excess at flowering (vegetative competition)
→ Boron deficiency (pollen tube fails)
→ Zinc deficiency (auxin not made — fruit not held)
→ Calcium deficiency (weak cell walls in fruitlet stalk)
→ Water stress during set
→ Poor carbohydrate reserves (weak tree, few leaves)
→ Heavy pest damage on leaves (less photosynthesis)
```

## Fruit Set Management Protocol

| Phase | Action | Why |
|-------|--------|-----|
| **Pre-bloom (build flower quality)** | Zinc + Boron + P (00:52:34) spray | Strong flowers set better than weak flowers |
| **Bloom** | Boron spray (Borax 2g/L or WAE) | Pollen tube germination — no B = no set |
| **Just after set** | NAA (Planofix) 1.5ml/4.5L | Auxin holds fruitlet — reduces post-bloom drop |
| **Cell division (weeks 2-6)** | Calcium (separate) + Zinc | Fruitlet stalk strength — reduces June drop |
| **Throughout set** | NO nitrogen, NO water stress | N causes drop, stress causes drop |

```
KEY INSIGHT FOR TWO-BAHAR:
The flower quality of THIS bahar depends on the tree's reserves from
the PREVIOUS crop. If the tree exhausted itself on the last bahar,
this bahar's flowers will be weak → poor set.
→ Solution: Strong nutrition AFTER each harvest to rebuild reserves
→ This is why post-harvest feeding is critical (see Two-Bahar section)
```

# SECTION 2 — IN-DEPTH: FRUIT SIZE

## The Science — Size = Cell Number × Cell Size

```
FRUIT SIZE IS DECIDED IN TWO PHASES:

PHASE 1 — CELL DIVISION (first 4-6 weeks after set):
→ Determines the NUMBER of cells in the fruit
→ More cells = potential for bigger fruit
→ Controlled by: Zinc, Boron, Phosphorus, cytokinins, GA3
→ This phase sets the CEILING on final size — cannot be recovered later
→ CHEMICAL BOOST: GA3 (Gibberellic acid) 10-20ppm at this stage
                  increases cell number → bigger fruit potential

PHASE 2 — CELL ENLARGEMENT (weeks 6 to maturity):
→ Determines the SIZE each cell reaches
→ Controlled by: Potassium (drives water into cells), water availability, Calcium
→ This is where most visible size gain happens
→ Adequate water + high K = maximum cell expansion

THE BIGGEST SIZE FACTOR — CROP LOAD:
→ Too many fruit on tree = each fruit gets less = SMALL fruit
→ Fewer fruit = each gets more resources = BIG fruit
→ THINNING excess fruit = bigger remaining fruit (see Section 5)
→ Leaf:fruit ratio matters — need 40-60 leaves per fruit for good size
```

## Fruit Size Management Protocol

| Phase | Action | Why |
|-------|--------|-----|
| **Cell division (weeks 2-6)** | GA3 10-20ppm + Zinc + Boron + balanced NPK | Maximize cell number = size ceiling |
| **Cell division** | Adequate N (after set) 19:19:19 | Protein for cell building |
| **Enlargement (K phase)** | High Potassium (SOP) + Calcium (separate) | Cell expansion + wall extensibility |
| **Enlargement** | Consistent water (no stress) | Water fills cells = size |
| **Throughout** | Control leaf miner (protect leaves) | Leaves = sugar factory = fruit food |
| **If heavy set** | THIN fruit (Section 5) | Fewer fruit = bigger fruit |

```
⚗️ GA3 (Gibberellic Acid) — the size booster:
→ 10-20 ppm spray during cell division phase (weeks 2-6 after set)
→ Increases cell division → more cells → bigger fruit
→ Also improves peel quality in some cases
→ Do NOT overuse — excess GA delays maturity and color
→ ONE or TWO applications during early fruit only
```

# SECTION 3 — IN-DEPTH: FRUIT QUALITY (Brix, Juice, Color, Peel)

## What Makes Quality

```
BRIX (Sugar / Sweetness):
→ #1 factor: POTASSIUM (SOP best for citrus)
→ Good leaf area + sunlight (sugar factory)
→ LOW nitrogen late (excess N keeps acidity high, dilutes sugar)
→ Mild water deficit in final weeks (concentrates sugar — "regulated deficit")

JUICE CONTENT:
→ Potassium + Calcium + consistent water
→ Avoid water stress during enlargement

ACIDITY (should reduce as fruit matures):
→ Excess nitrogen KEEPS acidity high → sour fruit
→ Potassium + maturity reduces acid → sweet fruit
→ Stop N early = acid drops naturally

PEEL COLOR (Mosambi should turn light green-yellow):
→ Cool nights trigger color (natural)
→ LOW nitrogen late (N keeps peel green)
→ Potassium helps color
→ Sunlight penetration (canopy management)

PEEL QUALITY (smooth, right thickness):
→ Balanced nutrition — excess N = thick coarse peel
→ Calcium + Boron = smooth firm peel
→ Consistent water = no cracking

GRANULATION (juice sacs dry out — quality defect):
→ Caused by: excess water/N late, oversized fruit, Ca imbalance
→ Prevent with: Calcium, controlled water late, K, avoid excess N
```

## Fruit Quality Management Protocol

| Target | Action | Why |
|--------|--------|-----|
| **High Brix** | SOP (00:00:50) 5g/L + stop N by P9 | K makes sugar, N dilutes it |
| **Good juice** | K + Calcium (separate) + steady water | Fills juice sacs |
| **Low acidity** | Stop nitrogen early + K | N holds acid |
| **Peel color** | Low N late + K + canopy light | Color needs low N + cool + sun |
| **Smooth peel** | Calcium + Boron + balanced feed | Prevents coarse thick peel |
| **No granulation** | Calcium + controlled late water | Ca stabilizes juice sacs |
| **Brix boost final** | Mild water deficit last 2-3 weeks | Concentrates sugar |

# SECTION 4 — IN-DEPTH: TWO-BAHAR TREE MANAGEMENT
## (The Special Challenge — Running Two Crops)

```
⚠️ CRITICAL WARNING — READ THIS CAREFULLY:

Running TWO bahars per year is VERY demanding on the tree.
The tree carries both crops at different stages simultaneously.
→ When Bahar 1 fruit is enlarging, Bahar 2 is flowering
→ Both crops compete for the same tree resources

RISKS OF TWO HEAVY BAHARS:
→ Tree exhaustion → decline → death over years
→ Small fruit (resources split between two crops)
→ Poor quality (not enough K/nutrition for both)
→ Alternate bearing worsens (heavy then nothing)
→ Weak flowers next cycle (no reserves rebuilt)
→ Disease susceptibility (weak tree)

THE GOLDEN RULE OF TWO-BAHAR:
→ Do NOT let BOTH bahars be heavy
→ Take ONE MAIN bahar (heavy) + ONE LIGHT bahar
→ OR alternate: strong Mrig one year, strong Ambia next year
→ A tree can support ~one full crop worth of quality fruit per year
→ Splitting into two = each must be lighter for good size/quality
```

## How to Maintain Quality + Size with Two Bahars

| Requirement | What To Do |
|-------------|-----------|
| **Strong root system** | VAM every cycle, mulching, organic matter, avoid root damage |
| **Rebuild reserves** | HEAVY feeding immediately AFTER each harvest (rest + rebuild) |
| **Crop load balance** | THIN one bahar to keep it light — never two heavy crops |
| **Extra nutrition** | Two crops need ~1.5x normal nutrition (not 2x, but more) |
| **Canopy health** | Prune for light + air — a healthy canopy feeds both crops |
| **Monitor vigor** | If tree looks weak/pale → drop to ONE bahar that year |
| **Post-harvest recovery** | 30-45 day recovery feeding after each harvest (critical) |
| **Micronutrients** | Zn/Fe/B/Mn — two crops deplete these fast at pH 8.2 |

```
POST-HARVEST RECOVERY (do after EACH bahar harvest — non-negotiable):
→ Prune dead/weak wood
→ Heavy organic: EJEV 20% drip + FYM 40kg/tree + compost
→ NPK 19:19:19 to rebuild + micronutrients
→ TRCH + VAM to restore root health
→ This rebuilds reserves for next bahar's flower quality
→ SKIP this = weak flowers + poor set next cycle
```

# SECTION 5 — IN-DEPTH: CROP LOAD & FRUIT THINNING
## (The Secret to Big Fruit — Most Farmers Skip This)

```
WHY THINNING MATTERS:
→ Citrus oversets, then June-drops, but often STILL too many fruit
→ Too many fruit = small fruit + poor quality + tree exhaustion
→ Removing some fruit = remaining fruit get BIGGER + sweeter
→ With TWO bahars, thinning is ESSENTIAL (can't carry two heavy loads)

WHEN TO THIN:
→ After June drop (natural drop finishes, ~6-8 weeks after set)
→ When you can see the real crop load

HOW TO THIN:
→ Remove: small fruit, damaged fruit, fruit in dense clusters
→ Remove: fruit touching each other (disease + rub marks)
→ Keep: healthy, well-spaced, single fruit
→ Target: proper leaf:fruit ratio (40-60 leaves per fruit)

TARGET FRUIT LOAD (8-year Mosambi, good canopy):
→ Full single bahar: ~400-600 fruit per tree for quality size
→ If two bahars: ~250-350 per bahar (lighter each)
→ Overloaded tree (800+ fruit) = all small, low value

CHEMICAL THINNING (optional, at scale):
→ NAA at higher dose can thin (but tricky — can over-thin)
→ Hand thinning is safer for quality growers
```

# SECTION 6 — IN-DEPTH: CANOPY & ROOT MANAGEMENT

## Canopy (Pruning for Quality)

```
WHY PRUNE:
→ Light penetration → better color + Brix on inside fruit
→ Air circulation → less canker, gummosis, fungal disease
→ Remove disease sources (dead wood, water shoots)

WHAT TO PRUNE (during stress period, before each bahar):
→ Dead, diseased, broken branches
→ Water shoots (vertical vigorous shoots — no fruit, waste energy)
→ Criss-crossing branches (rub wounds = disease entry)
→ Suckers from rootstock (below graft)
→ Skirt pruning: raise lowest branches 45-60cm off ground
  (prevents gummosis, soil splash disease, easier spraying)
→ Center opening: let light into the middle of canopy
→ ALWAYS: TRCH paste on cuts immediately (prevent gummosis entry)
```

## Root Zone (Foundation of Everything)

```
CITRUS FEEDER ROOTS: top 30-60cm, spread to canopy edge
→ Mulching (6 inch) — keeps roots cool, moist, feeds soil biology
→ Organic matter (FYM, compost) — builds CEC, buffers pH 8.2 over time
→ VAM every cycle — unlocks P/Zn/Fe at pH 8.2 (essential)
→ Avoid deep tillage near tree — damages feeder roots
→ Avoid waterlogging — citrus roots die in standing water (root rot)
→ Gypsum for black/heavy soil — improves drainage + adds Ca+S
```

# SECTION 11 — MONITORING CHECKLIST (Every 15 Days)

```
FRUIT SET:
□ Count fruitlet retention — excessive drop? → NAA + Calcium + check N
□ Leaf color — yellow? → Fe-EDDHA (chlorosis at pH 8.2)
□ New flush — leaf miner damage? → Imidacloprid/Spinosad

SIZE:
□ Measure 10 random fruit diameter each period — on track?
□ Crop load — overloaded? → THIN
□ Leaf:fruit ratio — enough leaves per fruit?

QUALITY:
□ Brix test (last third) — rising? → more K, less N
□ Peel — cracking? → Calcium + steady water
□ Color developing? → check N stopped, K adequate

TREE HEALTH (two-bahar critical):
□ Overall vigor — pale/weak? → reduce to one bahar, recovery feed
□ Trunk — gummosis oozing? → TRCH + Ridomil
□ Root zone — waterlogged? → drainage (root rot risk)

DISEASE/PEST:
□ Canker spots? → Copper + Streptocycline
□ Psylla present? → Imidacloprid (greening vector!)
□ Fruit fly? → traps
```
