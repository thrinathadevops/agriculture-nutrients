## 1.1 — Why Soil Comes First

```
A tree grows from the SOIL. Sprays are only vitamins on top of the food.
If your soil is alive and rich, you need FEWER sprays and get BETTER fruit.
At pH 8.2, organic matter is doubly important — it slowly buffers pH,
feeds the microbes (VAM, PSB) that unlock locked Fe/Zn/P, and holds moisture.
Build the soil, and everything else becomes easier.
```

---

## 1.2 — FYM (Farm Yard Manure): The Bulk Base

### What It Is
```
Well-rotted cattle dung + urine-soaked bedding (straw, dry leaves, crop residue).
The BULK organic matter — builds structure, holds water, feeds earthworms,
buffers pH 8.2 over years. This is your soil's staple food.
```

### Preparation
```
1. Layer cattle dung + bedding (straw/leaves) alternately in a heap or pit
2. Sprinkle water — keep MOIST like a squeezed sponge (never soggy)
3. Turn every 3-4 weeks (air speeds decomposition)
4. Cover with thin soil/straw layer
5. Ready in 3-4 months when:
   → Dark brown, crumbly
   → Earthy smell (NO dung smell)
   → Original material unrecognizable
   → COOL to touch (finished — this "cool" test matters for summer safety)
```

### Quantity for 1000 Trees
```
Per tree per YEAR:        35 kg well-rotted FYM
Per tree per BAHAR:       17-18 kg (split — before each bahar)
For 1000 trees per YEAR:  35 TONNES
Per application (1 bahar): ~17.5 TONNES

RAW MATERIAL NEEDED (loses ~50% mass while rotting):
→ ~65-70 tonnes raw dung + bedding/year to yield 35 tonnes FYM
→ One cow gives ~5-8 t dung/year → need 8-10 cattle, OR buy rotted FYM from dairies
```

## 1.5 — THE SUMMER MANURE QUESTION (Explained)

```
DOUBT: "People say don't put manure in summer (it heats soil). You say give it. Which?"

BOTH ARE RIGHT — it depends on the manure TYPE:

❌ RAW / FRESH / HALF-ROTTED manure in summer = HARMFUL
   → Still decomposing → decomposition GENERATES HEAT
   → In hot soil, extra heat + ammonia can BURN feeder roots
   → THIS is what old farmers correctly warn against

✅ FULLY DECOMPOSED compost + FYM in summer = BENEFICIAL
   → Stable, decomposition finished → NO heat generation
   → Cool, dark, crumbly → actually COOLS soil (mulch effect), holds moisture
   → Feeds soil life during heat stress

THE RESOLUTION:
→ The warning is about RAW manure. Your Sanjivani (40 days) + FYM (3-4 months)
  are FULLY ROTTED → safe and helpful even in summer.
→ The test: COOL to touch, crumbly, earthy smell = safe to apply.
→ NEVER apply fresh dung in summer.

SAFEST TIMING:
→ Apply main manure at START of each bahar (soil being watered anyway):
  • Mrig bahar: early July (monsoon cools things)
  • Ambia bahar: late December (winter, cool — ideal)
→ AVOID large fresh applications in April-May peak dry heat.
→ If feeding in summer: well-rotted only + under mulch + water in.
```

## 1.6 — HOW TO APPLY MANURE (Method)

```
WHERE — at the CANOPY DRIP-LINE (circle under the outer branch edge):
→ This is where feeder roots feed. NOT at the trunk (rot risk + no feeder roots there).

HOW — step by step:
1. Clear mulch aside in a band at the drip-line (OR shallow trench 10-15cm)
2. Spread FYM + Sanjivani in the band
3. Lay ON TOP + light shallow mix only (NEVER deep-dig — cuts feeder roots)
4. DRENCH with Jeevamrutha 10% (20L Jeevamrutha in 200L water) over the band
   → Activates microbes, speeds nutrient release
5. Cover with 6-inch MULCH (straw / dry leaves / sugarcane trash)
6. IRRIGATE to settle

TOP vs DIG — the answer:
→ BEST (least root damage): lay on top + Jeevamrutha drench + mulch + irrigate
→ Light shallow mix is fine to speed availability
→ NEVER deep-dig manure into citrus root zone

FREQUENCY:
→ Main dose: before each bahar (2× year)
→ Jeevamrutha drench: continues through drip calendar
→ Mulch: keep 6 inches year-round (top up as it rots down)
```

---

## 1.7 — MULCHING (Do Not Skip)

```
WHY: Cools roots in summer (your heat solution), holds moisture (less drop + cracking),
     slowly builds humus (buffers pH 8.2), suppresses weeds, protects the manure.
MATERIAL: Paddy straw, sugarcane trash, dry leaves, groundnut shells.
THICKNESS: 6 inches, in a ring at drip-line, 15cm gap from trunk.
BONUS: Neem leaves in mulch = slow pest deterrent.
```

## 2.2 — The Golden Rule of Two Bahars

```
⚠️ Do NOT let BOTH bahars be heavy. One MAIN (heavy) + one LIGHT.
→ Two heavy crops = small fruit + exhausted tree + slow decline.
→ The tree carries both crops at once (one enlarging while other flowers).
→ Manage crop load by THINNING (Part 5).
→ If tree looks pale/weak in any year → take only ONE bahar that year.
```

## 2.3 — Why Post-Harvest Recovery Is the Secret

```
Each bahar's FLOWER QUALITY depends on reserves rebuilt after the PREVIOUS harvest.
→ Exhausted tree → weak flowers → poor set → poor crop.
→ Well-fed-after-harvest tree → strong flowers → good set → good crop.
This is why POST-HARVEST feeding (Part 7) is non-negotiable for two-bahar farms.
```

# PART 3 — STRESS & FLOWERING (Controlled, No Rain Dependency)
# ═══════════════════════════════════════════

## 3.1 — Controlled (Drip) Stress Is BETTER Than Rain

```
In January (Ambia), no rain — you control everything by drip:
→ To STRESS: STOP the drip → soil dries → tree goes dormant
→ To RELIEVE: START the drip → tree wakes → flowers

THIS IS THE BETTER BAHAR:
→ You control the stress fully → no rain to break it halfway
→ Uniform stress → UNIFORM flowering (solves your July problem)
→ The January (Ambia) bahar = your most reliable, even flowering
→ The July (Mrig) bahar = rain risk → manage carefully (extend stress if rain comes)
```

## 3.2 — The Flowering-Boost Protocol

```
STEP 1 — COMPLETE STRESS (15-20 days, no drip):
→ Mild leaf wilt / slight yellowing = correct. No water, no spray. Tree rests.

STEP 2 — APPLY MANURE (before giving water):
→ FYM 17kg + Sanjivani 5kg per tree at drip-line + Jeevamrutha drench + mulch

STEP 3 — GIVE WATER + FLOWERING SPRAY:
→ Start drip (light first, then normal)
→ 🌿 FLOWERING SPRAY (Day 1 + Day 10):
   MKP (00:52:34) 5g/L + Zinc Sulfate 5g/L + Borax 2g/L → whole canopy
   = High P + K + Zinc + Boron, ZERO Nitrogen → TRIGGERS FLOWERS
→ These 3 MIX in one tank. NO UREA.

STEP 4 — DRIP (basal flowering nutrition):
→ Jeevamrutha/EJEV + MOE (K + pH) + VAM. NO nitrogen until fruit sets.

⚠️ NEVER UREA/NITROGEN AT FLOWERING → this gave you shoots instead of flowers.
   Nitrogen = leaves. MKP (P+K) = flowers. Remember forever.
```

## 3.3 — If Rain Breaks the Stress (July Bahar)

```
LIGHT rain (soil not fully wet): EXTEND stress 7-10 more days. No water, no urea yet.
HEAVY rain (stress broken): Once soil workable, spray MKP 5g/L to force flowering.
   NEVER apply urea after rain-broken stress (this caused your uneven flowering).
If already watered + fertilized wrong: STOP nitrogen, spray MKP, re-stress
   the vegetative (shoot-only) trees 7-10 days, tip-prune shoots, then MKP again.
```

## 3.4 — FLOWERING TROUBLESHOOTING (When Flush/Buds Don't Come)

```
THE COMMON PROBLEM (well-known in citrus):
1. Pruned branches ✅
2. Gave water (10-15 days) ✅
3. Rain fell in the middle ❌ (broke stress)
4. New sprout/flush did NOT come properly, OR shoots came not buds
→ This is a KNOWN citrus problem. The principle: MORE STRESS = MORE FLOWERS.
  Rain removes the stress, so flowering fails.

━━━ THE SAFE METHOD (always try this FIRST) ━━━
STEP 1: Wait for soil to dry back to mild stress (leaves dull, no new weeds)
        — do NOT spray MKP onto wet/rain-soaked soil (weak result)
STEP 2: When tree is in mild stress, spray (all MIX, one tank, per 1000L):
        → 00:52:34 (MKP) 5 kg  +  13:00:45 (KNO3) 5 kg  +  Boron 2 kg
          (high P + high K, ZERO nitrogen = flowering trigger)
        → Optional: Wettable Sulphur 2-2.5 g/L (mild fungicide, can add)
STEP 3: Repeat after 10-15 days. Flower buds should appear.
STEP 4: NO urea, NO nitrogen anywhere near flowering.

━━━ PACLOBUTRAZOL — LAST RESORT ONLY (⚠️ strong chemical) ━━━
Paclobutrazol 23% SC (Cultar) @ 1-2 ml/L is a growth retardant that FORCES
flowering by stopping shoot growth. It works, but with SERIOUS cautions:

⚠️ USE ONLY IF: stress + MKP repeatedly fails AND trees are MATURE (8-year)
⚠️ NEVER on young 2-year trees or any young plant (permanent stunting)
⚠️ Long soil residual (1-2 years) — affects future growth
⚠️ OVERDOSE = permanent damage, cannot be reversed → start LOW (1 ml/L)
⚠️ Some export markets restrict paclobutrazol residue
⚠️ Consult local horticulture officer before using

RULE: Master natural stress + MKP first. Paclobutrazol is a powerful
      last-resort tool for mature trees only — never the first choice.
```

# PART 4 — FRUIT SET, SIZE & QUALITY (The Science)
# ═══════════════════════════════════════════

## 4.1 — Fruit Set (Reduce the Drop)

```
Citrus makes 100,000+ flowers, sets only 1-2%. Everything else drops.
TWO drop waves: post-bloom drop + June drop (physiological).

YOUR ENEMIES (cause excess drop):
→ Nitrogen at flowering, Boron deficiency, Zinc deficiency, Calcium deficiency,
  water stress, weak tree (few leaves), heavy pest damage.

YOUR TOOLS (reduce drop):
1. Boron at bloom (pollen tube)
2. NAA (Planofix) after set (auxin holds fruitlets)
3. Calcium (strong fruitlet stalk)
4. NO nitrogen until firmly set + steady water
```

## 4.2 — Fruit Size (= Cell Number × Cell Size)

```
PHASE 1 — CELL DIVISION (first 4-6 weeks): sets NUMBER of cells = SIZE CEILING.
   → Controlled by Zinc, Boron, Phosphorus, GA3. Cannot be fixed later.
   → GA3 10-20ppm here = more cells = bigger fruit potential.
PHASE 2 — CELL ENLARGEMENT (later): sets SIZE of each cell.
   → Controlled by Potassium (drives water in), steady water, Calcium.
BIGGEST FACTOR — CROP LOAD: too many fruit = all small. THIN for size (Part 5).
Also: leaf:fruit ratio (~40-60 leaves/fruit). Protect leaves (leaf miner control).
```

## 4.3 — Fruit Quality (Brix, Juice, Color, Peel)

```
BRIX (sweetness): Potassium (#1) + sunlight + LOW nitrogen late + mild late deficit.
JUICE: Potassium + Calcium + steady water.
ACIDITY (should drop): excess N keeps it high → stop N early → acid falls → sweet.
PEEL COLOR: cool nights + low N late + K + sunlight (pruning).
PEEL QUALITY: balanced feed + Calcium + Boron (excess N = thick coarse peel).
GRANULATION (juice sacs dry — defect): prevent with Calcium + controlled late water + K.
```

# ═══════════════════════════════════════════
# PART 5 — CROP LOAD & THINNING (Secret to Big Fruit)
# ═══════════════════════════════════════════

```
WHY: Citrus oversets → even after June drop, often too many fruit → small fruit.
     Removing some = remaining fruit get BIGGER + sweeter. Essential for two-bahar.

WHEN: After June drop finishes (~6-8 weeks after set) — Period 6.

HOW: Remove small, damaged, clustered, touching fruit. Keep healthy, well-spaced.

TARGET (8-year tree, good canopy):
→ Single full bahar: ~400-600 fruit/tree for quality size
→ Two bahars: ~250-350 per bahar (keep each lighter)
→ Overload (800+): all small, low value — avoid
```

# PART 9E — THE STAGE RULE + SOIL-FIRST (ONBA Science)
# ═══════════════════════════════════════════

```
THE TRUTH THAT SAVES MONEY:
→ N-P-K is only 5% of the plant. Carbon+Oxygen+Hydrogen = 90% (free, from air+water
  — IF soil is alive). So fix the SOIL first, then give nutrients at the RIGHT STAGE.
→ Too much of a nutrient is as harmful as too little. Right timing = half the cost.
```

## THE STAGE RULE (give MORE in one stage, LESS in others)

| Nutrient | Give MORE in | Give LESS in |
|----------|-------------|-------------|
| Nitrogen | GROWTH | flower + fruit |
| Magnesium | GROWTH | flower |
| Phosphorus | FLOWER (bud) | growth + fruit |
| Sulfur | FLOWER | growth |
| Boron | FLOWER (set) | (max 2 g/L — toxic if more) |
| Potassium | FRUIT | growth + flower |
| Calcium | FRUIT | flower |
| Zinc | every new flush | (holds flower/fruit) |

```
⚠️ DAP MISTAKE: DAP broadcast in soil at ploughing turns to locked SALT in 15 days
   = wasted + poisons soil over years. Give phosphorus at BUD stage (foliar MKP), not soil.
⚠️ NITROGEN EXCESS: tall leafy soft growth, pest magnet, LOSES flowering power, green
   coarse fruit. Farmers feel happy seeing the flush — it costs them the crop.
```

## SOIL-FIRST (do this or fertilizer is wasted)

```
1. SOIL TEST every 3 years — NPK + Ca/Mg/S + micros + CARBON% + pH.
2. BUILD SOIL CARBON to 2% (yours ~0.2-0.5%): FYM, vermicompost, oil cake, green
   manure (grow + plough in 40-50 days between crops), fulvic/humic/amino acid.
3. LOOSEN SOIL so roots get OXYGEN (density 1.1-1.6, not 2.5-3) — organic matter does this.
4. FIX pH 8.2 → 6.5-7.0: MOE in every drip, Fe-EDDHA for iron, organic matter over years.
5. PRE-PLANTING SOIL TREATMENT: grow Trichoderma + Pseudomonas + Bacillus +
   bio-fertilizers (Azotobacter, PSB, KMB) in well-rotted FYM 10-15 days, spread on
   moist soil. This revives dead soil so nutrients finally work.
```

## THE SPRAY TIP THAT SAVES 50%

```
⭐ SPRAY THE UNDERSIDE OF LEAVES (nozzle pointed UP from below, 45°+).
The underside has ~2× the pores (stomata), bigger + more open. Spray entering the
underside spreads to the WHOLE plant; top-surface spray does not. Pests + fungi hide
underneath too. Top-only spraying wastes ~50% — fixing this halves your cost.

Also: spray WITH the wind. Roots take 90% of nutrients (feed soil first); foliar only
to fix visible deficiencies fast. Test-mix before combining products. Max 120 L/acre.
```
