## 🌸 ── FLOWERING STAGE ──

## MOE — Mosambi/Citrus Extract ⭐ (pH corrector, every drip)

### 🧪 WHAT IT IS
```
Fermented extract of waste citrus fruit — citric acid + potassium + microbes.
Your #1 fix for pH 8.3 alkaline borewell water.
```

### 📥 INGREDIENTS + HOW TO PREPARE
```
→ Waste/fallen citrus 2-3 kg + water 20 L + jaggery 250 g
1. Crush fruit into plastic container (never metal)
2. Add water + jaggery, ferment 5-7 days in shade, stir daily
3. Strain → clear MOE ready
```

### 🧬 KEY NUTRIENTS & COMPOUNDS (with % where known)
```
→ Citric acid ....... main (acidifier + chelator) — homemade, ~3.0-3.5 pH
→ Potassium (K) ..... small amount (variable)
→ Vitamin C, flavonoids (immunity)
→ LAB + yeast (soil microbes)
(homemade = variable %, not lab-standardized)
```

### 🌿 WHAT THE PLANT GETS EXACTLY
```
→ Citric acid lowers 8.3 → 6.5-7.0 → UNLOCKS locked iron/zinc/phosphorus → plant absorbs them
→ Chelation: grabs Fe/Zn into absorbable form = FREE natural chelator (partly replaces Fe-EDDHA)
→ Potassium: sugar movement, fruit quality
→ NET: greener leaves, better uptake of ALL inputs, less salt/pH stress. pH effect INSTANT.
```

### 📊 DOSE + WHEN (best time)
```
→ DRIP: 3 L per 200L drum — EVERY drip (critical at pH 8.3)
→ BEST TIME: anytime for drip; evening if sprayed
→ STAGE: all stages, critical flowering onward
```

### 📦 STORAGE & SHELF LIFE
```
→ 3-6 months: ferment fully + strain + extra jaggery + sealed + cool. Sour=good, rotten=discard.
```

### ⭐ UNIQUE BENEFIT
```
The ONLY input that fixes your ROOT problem (pH 8.3 lock). Free (farm waste), and makes every
other expensive input actually work by unlocking it. Nothing else does this at zero cost.
```

### ❌ DO NOT MIX WITH
```
→ Copper/alkaline chemicals (neutralize). Don't add to fish sump (drops pH, kills fish — drum only).
```

### 🔬 SCIENCE / VERDICT
```
✅ Verified chemistry: citric-acid chelation + pH drop unlock nutrients at high pH.
✅ Your most valuable cheap input. Never skip in drip. ⚠️ Weak at sump scale — use in 200L drum.
```

# 🔬 MULTIPLICATION GUIDE — Re-growing Your Cultures (CFU, Food, Honest Limits)
## For EM, Trichoderma, Pseudomonas, PBC — will home-multiplied match the bought count?

### ⚠️ THE HONEST TRUTH ABOUT CFU COUNT (read first)
```
Your bought culture = 1 billion (10^9) CFU/gram, made in a STERILE LAB (pure strain, controlled
temp, exact food). At home you CANNOT match this. Here's why + what to do:

→ Home multiplication grows your good strain BUT also wild/contaminant microbes (they compete).
→ You can't control temperature + sterility like a lab.
→ Each generation from your OWN batch = weaker + more contaminated.
  Gen 1 (from bought pack) = fairly good | Gen 2 (from your batch) = weaker | Gen 3+ = degraded.

✅ THE RULE: Multiply from a FRESH BOUGHT pack EACH cycle. Don't keep re-growing from your own
   old batch. You still save money (1 pack → many litres), but always start from fresh culture.
❌ DON'T: take last month's home brew → re-multiply → repeat. Quality + count drop each time.
```

### 🍽️ BEST FOOD FOR MULTIPLICATION (per culture — your jaggery/yeast/potato question)
```
JAGGERY (simple sugar) = universal microbe food → best for EM, Pseudomonas, general bacteria.
BESAN/GRAM FLOUR (protein) = for bacteria that need protein → Pseudomonas, Bacillus.
BOILED POTATO (starch) = ⭐ BEST for FUNGI (Trichoderma) — potato dextrose is the LAB standard
   fungal medium. Fungi love potato starch.
RICE FLOUR (starch) = cheap carbon for fungi + general.
YEAST = itself a microbe (part of EM) — NOT a food to add; it's a co-organism.
```

### 📋 EXACT MULTIPLICATION — EACH CULTURE

RECIPE: EM.1 1 L + jaggery 1 kg + clean water 18-20 L → airtight 5-7 days, release gas daily
