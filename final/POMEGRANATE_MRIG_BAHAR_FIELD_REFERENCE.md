# ⚡ THE MIXING RULE (Never Forget)

```
✅ MIX in one tank: MKP, Zinc, Boron, NPK, Iron, NAA, GA3, SOP, Kaolin
❌ CALCIUM = always separate spray (ruins P/S → white sludge)
❌ COPPER + antibiotics = always separate (kill biologicals)
❌ BIOLOGICALS (Jeevamrutha/VAM/Trichoderma/PLF) = never with chemicals
```

---

# ⚡ THE 5 RULES YOU CANNOT BREAK

```
1. FLOWERING = MKP (00:52:34) + Zinc + Boron. NEVER urea.
2. NITROGEN only after fruit set. STOP by Period 9 (for red color).
3. CALCIUM always a separate spray.
4. IRON = Fe-EDDHA only (drives Bhagwa red + fixes yellow leaves).
5. BLIGHT: Copper+Streptocycline in rain. Stop ALL chemicals 30-40 days pre-harvest.
```

# 🌱 SOIL & MANURE (Do Before Bahar — 2000 Trees)

```
PER TREE:  FYM 35 kg + Sanjivani compost 5 kg
TOTAL:     FYM 70 tonnes + Sanjivani 10 tonnes

SANJIVANI (10 t batch): dung 10t + goat 850kg + poultry 850kg
   + bonemeal 170kg + ash 170kg + press mud 850kg + Jeevamrutha 600-1000L
   → ferment 40 days → dark, crumbly, COOL

HOW: at drip-line (NOT trunk) → lay on top → Jeevamrutha drench → 6-inch mulch → water
SUMMER OK if WELL-ROTTED (cool/crumbly). Never raw manure in heat.
NEVER deep-dig (cuts feeder roots).
```

---

# 💧 DRIP DRUM STANDARD MIXES (200L, add MOE 2L each for pH)

```
FLOWER DRIP:   VAM 10L + MOE 2L  |  EJEV 30L + MOE 2L
NUTRITION:     MOE 2-4L + Jeevamrutha 20L (+ NPKD 8L when N allowed)
WILT GUARD:    Trichoderma 10L + PLF 6L + MOE 2L  (every period)
CALCIUM:       Calcium Nitrate 5g/L + MOE 2L  (SEPARATE session)
Flush 15 min plain water after every organic drip.
```

# 🌿 SPRAY QUICK MIXES (1000L Tank)

```
FLOWERING (P1):   MKP 5kg + Zinc 5kg + Borax 2kg → canopy (Day 1 + 10)
BLOOM (P2):       Borax 2kg + Zinc 5kg → evening only
FRUIT SET (P3):   EJEV 100L + NAA → morning | Calcium → evening (separate)
SIZE (P4):        GA3 15ppm + Zinc 5kg → morning
IRON (any):       Fe-EDDHA 1kg → if leaves yellow
QUALITY (P6-13):  SOP 5kg → canopy | Calcium separate | FAA+BSJ for red color
BORER (P5+):      Kaolin 5kg → on FRUIT only, reapply after rain
```

# 🚦 RAIN RESPONSE CARD

| Situation | Do This |
|-----------|---------|
| Rain forecast 1-2 days | Copper Oxychloride 2.5g/L (dry day before) |
| Light rain (1 day) | Continue organic + ALV/GGE next dry window |
| Heavy rain (2-3 days) | After: Copper 2.5g/L + Streptocycline 0.5g/L + Mancozeb 2.5g/L |
| Continuous 4+ days | Before: Copper Hydroxide 2g/L + Kaolin. After: full knockdown + remove infected |
| Oily black spots (Telya) | Copper + Streptocycline, stop bio drip 7 days, burn infected |
| Branch wilting | Cut + Trichoderma paste + Carbendazim 2g/L drench + PLF |
| Rain at flowering | Copper before/after + Boron + Calcium + CNW for set |
| Cracking after rain | Calcium + steady water + Kaolin |
| Borer in fruit | Remove + Kaolin double + Emamectin 0.4g/L + traps |

# 🚦 ORGANIC vs CHEMICAL — WHEN

```
🟢 GREEN (dry, no disease):        100% organic
🟡 YELLOW (rain forecast/spots):   organic + 1 preventive copper
🔴 RED (active blight/wilt/rain):  chemical priority, stop bio drip 7 days
⚫ HARVEST (last 30-40 days):      100% organic only (clean fruit)
Season average: ~70% organic, 30% chemical.
```

# 🔍 15-DAY CHECK

```
□ Telya black spots? → Copper+Streptocycline + remove
□ Branch wilting? → Carbendazim + cut + PLF
□ Leaves yellow? → Fe-EDDHA
□ Fruit dropping? → NAA + Calcium + no nitrogen
□ Overloaded? → THIN to 80-120 fruit/tree
□ Brix low (late)? → more SOP, zero N
□ Cracking? → Calcium + steady water + Kaolin
□ After rain? → reapply Kaolin + Copper/ALV
□ Mulch thin? → top up 6 inches
```
