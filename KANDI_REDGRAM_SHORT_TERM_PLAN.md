# 🌿 KANDI (RED GRAM / TUR / PIGEON PEA) — DETAILED PLAN WITH EXACT QUANTITIES
### Crop already 20 days old | Exact doses: per litre for spray, per drum for drip | No vague amounts
---
**Setup assumed:** 1000L spray tank + 200L drip drum. **Crop:** Kandi (Cajanus cajan), ~150-180 day crop.
**Your land:** rocky, well-drained, pH 8.3 — GOOD for kandi (it loves well-drained soil, hates waterlogging).

---

# ⚡ THE 3 GOLDEN RULES FOR KANDI (different from your trees)

```
1. NO NITROGEN (no urea, no high-N). Kandi FIXES ITS OWN nitrogen through root nodules
   (Rhizobium bacteria). Adding urea makes it LAZY → stops fixing → leafy plant, FEWER pods.
   → This also SAVES you money.

2. PHOSPHORUS + potassium are the key nutrients (for roots, nodules, then pods).

3. KEEP IT DRY-ISH. Kandi is drought-hardy and HATES wet feet (root rot). Light irrigation,
   let soil dry between. Your rocky land drains well = perfect for kandi.
```

# 📏 WHAT "SMALL QUANTITY" ACTUALLY MEANS (exact numbers)

```
SPRAY (per litre → per 1000L tank):
→ "light foliar" liquid input = 1-2 ml per litre = 1-2 litres per 1000L tank
→ "light foliar" powder input = 2-5 g per litre = 2-5 kg per 1000L tank
→ neem = 5-10 ml per litre = 5-10 litres per 1000L tank
→ micronutrient (Zinc/Boron) = 2-5 g per litre = 2-5 kg per 1000L tank

DRIP (per 200L drum):
→ liquid biological (Jeevamrutha/bio-brew) = 10-20 litres per 200L drum
→ culture (PSB/Rhizobium) = 1-2 litres (or as label) per 200L drum
→ MOE (pH correct) = 2-4 litres per 200L drum
→ soluble fertilizer = 200-500 g per 200L drum

⚠️ For a SMALL kandi plot you rarely need a full 1000L tank. Scale DOWN:
→ Knapsack sprayer (15-16L): use the per-litre dose × 15
   Example: neem 5ml/L → 75-80 ml in a 16L knapsack.
→ Only mix what you will spray that day.
```

# 🌱 STAGE-BY-STAGE PLAN (from Day 20, where you are now)

## STAGE 1 — EARLY VEGETATIVE (Day 20-35) — ROOTS + NODULES
### Goal: strong roots, active nitrogen-fixing nodules, branching. Focus = Phosphorus + microbes.

### 💧 DRIP (do now, Day 20-22)
```
In 200L drip drum:
→ Jeevamrutha OR your Pseudomonas+Bacillus brew ...... 15 L
→ PSB (Phosphate Solubilizing Bacteria) ............... 1-2 L (or per label)
→ Rhizobium culture (if you have it) .................. 1-2 L
→ MOE (for your pH 8.3 water) ......................... 3 L
→ Fill to 200L with water
→ Run through drip. Repeat this drip every 12-15 days.

WHY: PSB + Rhizobium build the roots + nodules that feed the WHOLE crop.
This is the single most important thing at Day 20.
```

### 🌿 SPRAY (Day 22-25, evening) — knapsack doses shown
```
Per litre (× your sprayer size):
→ Seaweed extract (SAG) ............ 2 ml/L   (16L knapsack = 32 ml)
→ NO nitrogen, NO urea
→ Fill, spray on leaves evening

Optional light phosphorus push (roots + nodules):
→ MKP (00:52:34) ................... 3 g/L    (16L = ~48 g)
   OR DAP foliar .................... 5 g/L    (16L = 80 g)
→ MKP/DAP gives Phosphorus WITHOUT much nitrogen — correct for kandi.

WHY: gentle growth + phosphorus for roots. Do NOT overspray — kandi needs little at this age.
```

### 🐛 PEST WATCH (Day 20-35)
```
Watch for: leaf-eating caterpillars, aphids, jassids on tender growth.
→ NEEM ....... 5 ml/L (16L knapsack = 80 ml) — evening, every 12-15 days as PREVENTION
→ Only if heavy pest: add a chemical (see pest table below).
```

---

## STAGE 2 — LATE VEGETATIVE / PRE-FLOWERING (Day 35-50) — BUILD THE FRAME
### Goal: branching, strong canopy, prepare for flowering. Add Zinc + Boron now (for pods later).

### 💧 DRIP (Day 35-40)
```
In 200L drip drum:
→ Jeevamrutha / bio-brew .............. 15 L
→ MOE ................................. 3 L
→ (optional) KMB potassium bacteria ... 1-2 L
→ Fill to 200L, run drip. Repeat ~every 15 days.
```

### 🌿 SPRAY (Day 38-42, evening) — MICRONUTRIENTS FOR PODS
```
Per litre (× sprayer size). These MIX together in one tank (all Group A):
→ Zinc Sulfate ..................... 3 g/L    (16L = ~48 g)
→ Borax (Boron) .................... 2 g/L    (16L = ~32 g)
→ Seaweed (SAG) .................... 2 ml/L   (16L = 32 ml)
→ Fill, spray leaves evening.

WHY: Zinc + Boron NOW = more flowers + better pod set later. Boron especially = pod
formation. This is the key spray to prepare for flowering.
⚠️ Boron: never exceed 2 g/L (toxic if more).
```

### 🐛 PEST (Day 35-50)
```
→ NEEM 5 ml/L evening every 12-15 days.
→ Watch for pod borer moths starting to appear near flowering — traps help (below).
```

---

## STAGE 3 — FLOWERING (Day 50-75) — THE CRITICAL STAGE
### Goal: hold flowers, set pods. Focus = Phosphorus + Potassium + Boron. Protect from POD BORER.

### 🌿 SPRAY (at first flowering, ~Day 55, evening)
```
Per litre (MIX together — Group A):
→ MKP (00:52:34) ................... 5 g/L    (16L = 80 g)   [P+K, no nitrogen]
→ Boron (Borax) .................... 2 g/L    (16L = 32 g)
→ Seaweed (SAG) .................... 2 ml/L   (16L = 32 ml)
→ Fill, spray evening. Repeat once after 12-15 days.

WHY: P+K+Boron at flowering = maximum flower retention + pod set. NO nitrogen (drops flowers).
```

### 🌿 ANTI-DROP (if flowers dropping)
```
→ NAA (Planofix) .............. 1.5 ml per 4.5 L    (16L = ~5 ml) — reduces flower drop
   OR Coconut water 10% foliar (fresh)
```

### 🐛 POD BORER — THE #1 KANDI ENEMY (Helicoverpa) — Day 55 onwards
```
Pod borer caterpillar bores into pods + eats seeds = biggest kandi loss. Act at flowering.

ORGANIC first:
→ NEEM ................... 5-10 ml/L (16L = 80-160 ml) evening, every 7-10 days
→ Pheromone traps ....... 4-5 per acre (Helicoverpa lures) — catch the moths
→ Bird perches .......... let birds eat caterpillars (cheap + effective)

CHEMICAL if borer is heavy (see table):
→ Emamectin benzoate 5% .... 0.4 g/L (16L = ~6.4 g)
   OR Spinosad 45% .......... 0.3 ml/L (16L = ~5 ml)
   OR Chlorantraniliprole ... 0.3 ml/L (16L = ~5 ml) — very effective on pod borer
→ Rotate chemicals so borer doesn't build resistance.
```

---

## STAGE 4 — POD DEVELOPMENT / FILLING (Day 75-110) — FILL THE PODS
### Goal: fill pods, bold grain, weight. Focus = Potassium + Calcium. Keep protecting from borer.

### 🌿 SPRAY (Day 75-80, evening)
```
Per litre (MIX — Group A):
→ SOP (00:00:50, potassium) ........ 5 g/L    (16L = 80 g)   [K = grain fill + weight]
   OR MKP 5 g/L if no SOP
→ Seaweed (SAG) .................... 2 ml/L
→ Fill, spray evening. Repeat after 15 days.

SEPARATE spray (Calcium — never with above):
→ Calcium Nitrate .................. 5 g/L    (16L = 80 g)  OR egg-lemon extract (ELE)
→ evening, different session. Ca = firm grain, less pod drop.

WHY: Potassium fills the grain (weight + quality). Calcium holds pods. NO nitrogen.
```

### 🐛 CONTINUE POD BORER CONTROL
```
→ Neem 10 ml/L every 7-10 days + traps.
→ Chemical only if borer visible in pods (Emamectin/Spinosad/Chlorantraniliprole doses above).
→ ⚠️ STOP all chemicals 20-30 days before harvest (clean grain).
```

---

## STAGE 5 — MATURITY / HARVEST (Day 110-160+)
```
→ Stop irrigation as pods dry + turn brown.
→ No more spraying (only neem if needed — residue-free).
→ Harvest when 75-80% pods are dry/brown.
```

# ⚠️ THE MIXING RULE (same as your trees)
```
✅ MIX together (one spray): MKP, Zinc, Boron, Seaweed, Neem, DAP, SOP
❌ CALCIUM (Calcium Nitrate / ELE) = ALWAYS a separate spray (never with P or Zinc)
❌ CHEMICAL insecticide + biologicals = never together
❌ NO nitrogen/urea at any stage (kandi fixes its own)
```
